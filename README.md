# HT2026_GroupD_DINOv3

In this project we investigate different applications of DINOv3:
- drone tracking
- [Real-time 3D object distance estimation from a single RGB camera](./distance-estimation/) (Fahim)
- loop closure and long-term place recognition
- near and far medical images

## Project Structure & Branches

### `main` branch
- **[`distance-estimation/`](./distance-estimation/)**: Monocular depth estimation, NYU Depth v2 benchmarks, and real-time 3D object distance pipeline (DINOv3 + YOLO11).
- **[`loop closure/`](./loop_closure)** (marco) 

### Feature branches
- **`marco_branch`**: Loop closure
